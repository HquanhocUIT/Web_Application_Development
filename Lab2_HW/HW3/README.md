# Homework 3: High-Concurrency Flash-Sale E-Commerce Engine

Ứng dụng khởi tạo bằng React, TypeScript và Vite. Màn hình hiện tại chỉ là trang khởi đầu; countdown, inventory state machine và flash-sale engine sẽ được thực hiện ở các milestone sau.

## Chạy ứng dụng

Trong PowerShell trên Windows, chạy tại thư mục HW3:

```powershell
npm.cmd install
npm.cmd run dev
```

## Kiểm tra

```powershell
npm.cmd run build
npm.cmd run lint
```
