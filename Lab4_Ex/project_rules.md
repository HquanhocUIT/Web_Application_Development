# Project Rules — Lab 4 Exercises

## Phạm vi

- Lab 4 gồm 3 exercises. Tổ chức mỗi exercise trong một thư mục riêng dưới `Lab4_Ex`.
- Chỉ thực hiện exercise khi có yêu cầu cụ thể. Không tự ý khởi tạo dự án, cài dependencies hoặc viết code cho exercise trong lúc tạo file quy tắc này.
- Trước khi làm từng exercise, đọc đề bài tương ứng và tuân thủ đầy đủ yêu cầu, tiêu chí và phạm vi của đề.

## Công nghệ và cách viết code

- Sử dụng React, TypeScript và Vite cho mỗi exercise.
- Giữ code đơn giản, dễ đọc, dễ bảo trì; chia component và file theo nhu cầu thực tế, tránh cấu trúc hoặc trừu tượng hóa không cần thiết.
- Chỉ cài thư viện khi bài tập thực sự cần và thư viện đó phù hợp với yêu cầu đề bài.
- Dùng semantic HTML đúng ngữ cảnh. Đảm bảo accessibility, bao gồm nhãn cho điều khiển, thao tác bằng bàn phím và văn bản thay thế cho hình ảnh khi áp dụng.
- Thiết kế responsive để nội dung và chức năng sử dụng được trên màn hình nhỏ và lớn.

## Kiểm tra sau mỗi exercise

- Sau khi hoàn thành từng exercise, chạy kiểm tra TypeScript, ESLint và production build bằng các script hoặc lệnh phù hợp với dự án.
- Báo cáo kết quả kiểm tra thực tế; nếu chưa thể chạy một kiểm tra, nêu rõ lý do.

## Giới hạn tài liệu

- Không tạo file AI audit.
- Trong yêu cầu hiện tại, chỉ tạo `Lab4_Ex/project_rules.md`; chưa thực hiện bất kỳ exercise nào.
